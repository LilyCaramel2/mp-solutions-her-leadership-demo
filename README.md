# MP Solutions — HER Leadership Event Demo

A responsive event landing-page demo for **HER Leadership – Our Future**, hosted by 1000 Women Trust | 1000 Women, One Voice.

## Event

- 3 December 2026
- Cape Town International Convention Centre
- Ticket route: Webtickets
- Partnership route: 16days@1000women.co.za

## Preview locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy to Vercel

1. Open Vercel.
2. Select **Add New → Project**.
3. Import this repository.
4. Keep the framework preset as **Other**.
5. Select the repository root as the project root.
6. Deploy.

The page uses Tailwind CSS through the CDN and local image assets from the supplied event media.
