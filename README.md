# HER Leadership – Our Future

Responsive, single-page event website for **HER Leadership – Our Future**, hosted by 1000 Women Trust | 1000 Women, One Voice.

## Event details

- **Date:** 3 December 2026
- **Time:** 12:00
- **Venue:** Cape Town International Convention Centre (CTICC), Cape Town
- **Individual ticket:** R500 via [Webtickets](https://www.webticket.co.za/v2/event.aspx?itemid=1603494157)
- **Company booking:** R15,000; contact 16days@1000women.co.za
- **Partnerships:** Contact 16days@1000women.co.za for available options

## Local preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deployment

This static site is connected to Vercel. Updates pushed to the `main` branch trigger the production deployment. The page uses local image assets and plain HTML/CSS; there is no build step.

## Search metadata

The landing page includes a search/social description and `robots.txt` plus a one-URL `sitemap.xml` for the current Vercel domain. Update their URLs if the site moves to a custom domain.
